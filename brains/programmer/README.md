# Kai's Dev Brain (demo Brain)

A demo Brain for a made-up person. Kai Tanaka, Parcelwise, tidyq and everyone named here
are invented for this demo.

Kai is a backend engineer who uses coding assistants all day: at work on the routing
services of a logistics company, and at night on an open source task queue. This Brain
holds what every assistant should know without being told again: the machine, the stack,
the code style, the git rules, the services, and where each project stands.

What to try with it:

- Ask your coding assistant "review this diff" and see the review checklist and the code
  style arrive.
- Ask "how do we deploy the planner?" and get the deploy windows and the migration's state.
- Ask "where is tidyq 1.0?" for the release's latest progress.
