# Riley's Ventures (demo Brain)

A demo Brain for a made-up person. Riley Chen, Loopline, Brewbox, the investors and the
portfolio companies are all invented for this demo.

Riley runs one startup, carries the lessons of one that shut down, advises another, and
writes small angel checks. This Brain keeps every venture straight for every AI Riley uses:
the numbers, the round, the principles behind each decision, and who is who.

What to try with it:

- Ask "draft this month's investor update" and see the metrics and the update rules arrive.
- Ask "should we hire a second engineer before the seed closes?" for a decision framed by
  Riley's principles.
- Ask "what did I learn from Brewbox?" for the lessons and the postmortem.
