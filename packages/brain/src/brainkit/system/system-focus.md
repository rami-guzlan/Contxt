A Focus is ongoing work: a governed note of kind `focus` in its own project folder,
`knowledge/projects/<slug>/`, plus an append-only journal in `vault/journal/focus/<id>.jsonl`.
Its current state is the baseline overlaid with every journal change (status, current,
blockers, next, decisions). Notes filed in the same project folder, and the notes it pins,
come with it whenever the project is named. Name a Focus in a request to get its state; state
progress ("X approved the outline") to be told to record it with `projects_propose_progress`. Ask
what is active to get the portfolio. `projects_create` starts a new one with its own folder,
which applies immediately inside your own scope.
