# /knowledge-check

Check one thing against the Brain: a capture, a note, a draft, or text the person pastes.

## 1. Know what the Brain is for

Open the note `you-goals`: the owner's own answers about what this Brain should help them do.
If there is none, say so once in the result and judge by the person's request alone.

## 2. Read the thing in full

Split it into the points it makes: one statement each, in plain words, able to stand on its
own. Leave out small talk, task chatter and anything only true today.

## 3. Sort every point

Search the Brain for each point, in your own words and then in other words. Open the closest
notes in full before you decide. Each point is one of:

- **Known**: a note says the same. Name the note.
- **New**: nothing in the Brain covers it.
- **Disagrees**: a note says otherwise. Quote both, and say which looks current and why.
- **Updates**: a newer or fuller version of a note. Name the note.

## 4. Weigh it against the goals

For each new point or update, does it help the person do what the Brain is for? Mark the ones
that do not as off the goals, with a few words on why.

## 5. Report, shortest first

1. One line on how it fits, for example "Mostly known: 3 new points, 1 disagreement."
2. **Worth keeping**: the new points and updates that serve the goals.
3. **Disagreements**: each with both quotes and your recommendation.
4. **Off the goals**: what you would leave out, and why.
5. **Still unanswered**: what the Brain cannot answer about this subject yet, as questions.

## 6. Keep what is worth keeping

Propose each point worth keeping to the Brain, once: quote the source in the evidence, name the
note it replaces when it updates one, and the note it contradicts when it disagrees. In a
conversation, ask the person first. Run from the app, propose them directly: they wait for the
person in Catch up. Never change a note yourself. The person decides.
