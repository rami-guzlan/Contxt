1. Start from the regular version so both match question for question. 2. Break the page into chunks of no more than three questions, with a box around each chunk. 3. Add sentence starters for written answers, such as "I noticed that...". 4. Cut multiple-choice options from four to three and enlarge the font to 16 point. 5. Swap the blank diagram for a partly labeled one, save the file with the -adapted suffix next to the original, and tell Priya Raman which students (by initials) will get it.
