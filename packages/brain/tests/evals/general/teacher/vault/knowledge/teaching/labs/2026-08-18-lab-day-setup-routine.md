1. The afternoon before, fill one tray per station, label it with the station number and line the trays up on the back counter. 2. Before period 1, test each hot plate and run both eyewash stations for a few seconds. 3. At the bell, put up the safety slide and have the class repeat the goggle rule. 4. In the last five minutes, stations get wiped, trays come back and waste goes in the labeled bucket, never the sink. 5. Goggles go into the sanitizing cabinet for its 10-minute cycle before the next period.
