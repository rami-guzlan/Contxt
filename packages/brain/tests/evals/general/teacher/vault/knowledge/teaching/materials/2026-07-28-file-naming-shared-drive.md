All class files live in the shared drive folder "Whitaker Science 26-27", one subfolder per unit. Name files like U3-L05-density-lab (unit number, two-digit lesson number, short name) and add -v2 or -v3 for revisions instead of writing "final". Modified versions get the suffix -adapted. Answer keys go only in the "keys" subfolder and are never posted to the class page.
