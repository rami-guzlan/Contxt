Every figure in a funder report has to match the board dashboard for the same period. Give the exact number or round down, never up: "3.1 million pounds" only if it's at least 3,100,000. Marcus signs off on every submission and I review the operations section. If a funder asks for something we don't track, say so rather than estimate.
